# 引言

首先要明确我们想要做什么，微信小程序和微信小游戏是两个大类，因此需要先明确我们要做的是小程序还是小游戏，这两个大类的技术栈也并不相同。其次就是，明确一些限制，如果是个人开发者，则是有诸多限制的，除了无法经营金融、保险、医疗、教育等类目，最大的限制就是不能使用微信支付功能，因此，如果想实现盈利，则只能通过广告实现。企业开发者虽不受以上限制的影响，但也需要提交自己的营业执照等，并在自己的营业许可范围内提供服务。另外，小说和短剧小程序会受到更加严格的管控，需要有企业开发者身份的同时，还需要将视频和文字作品交给微信的管理平台进行管理，因为微信会禁用短剧小程序的video标签，不使用微信专用的短剧播放器，是无法播放视频的。

其他的就是善用开发者社区，微信的开发者社区会反馈各式各样的问题，有些问题即使没有定论，也会帮助你判断问题类型。

那么明确了以上几点后，我们就可以进行coding了。

# 准备工作

###### 1.注册开发者账号

首先，我们需要一个开发者账号，在微信公众平台可以找到小程序的注册入口： [微信公众平台-小程序](https://mp.weixin.qq.com/cgi-bin/wx) 

在填写了一些基本信息后，按照提示点击注册即可。需要注意的是，右侧有创建测试号的入口，测试号只是给了一个可供调试用的AppID和AppSecret，不能使用代码上传等功能。所以如果将来要发布而不是仅仅学习用，还是要注册一个开发者账号。

###### 2.下载IDE

微信提供了微信开发者工具，可以直接用微信开发者工具进行开发。微信开发者工具使用的是WXML，与HTML类似，但是在一些地方做了修改，比如我们熟知的div标签应写成view标签，如果你写div标签，则会报错。其次就是微信开发者工具提供了调试功能，可以使用类似浏览器F12的功能查看你的代码效果。

如果你有现成的vue工程，或者并不想重新学习WXML的一些语法，则可以尝试使用uniapp，它会帮你把vue代码编译为小程序代码，只需要在uniapp中配置好你的开发参数。

下载链接如下，无论你使用哪种工具，微信开发者工具是必须要下载的，即使使用uniapp，也需要在开发者工具上调试。

[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 

[uni-app官网](https://uniapp.dcloud.net.cn/) 

###### 3.认证和备案

如果想发布小程序，必须要经过认证和备案，而且在你给小程序命名之后，备案填写的小程序名称就必须和小程序名相同。之后虽然可以再次修改小程序名称，但是也需要同步的修改并重新提交备案，因此备案时要把名称和服务内容等一切都考虑清楚。

认证非常的简单，只需要在后台的微信认证一栏，支付认证费用就可以，个人是30元，企业300元，过了一年的认证期限后，需要重新认证。

小程序备案需要通过微信团队和管局两个部门，微信团队只负责审核你提交的信息是否全面，是否有不规范情况，相当于格式审查，记得有一次被微信团队驳回，理由是身份证的正反面没有在同一张桌子上，所以还是比较严格的。并且你的备注也要尽量写明经营范围，企业备案要说明你的小程序涉及什么服务，不涉及什么服务，个人备案在备注里加上**不涉及服务性和经营性**，这些承诺在微信团队的审查范围内。管局则会审查你的营业执照一类的内容，并且都会以打电话和发短信的方式向你核查。收到管局的短信后，要根据引导在24h之内登录工信部核验。

你会感觉到这部分的流程会比较慢，大约一周才能审核完，备案后就可以正常发布你的小程序了。

# 开发工作

小程序的开发相比准备工作，相对要考虑的少得多。代码的实现部分在本篇文章中，并不会详细介绍，而是侧重于如何使用工具，代码部分我将会在另一篇文章中说明。

###### 1.代码调试

搭建了相应环境之后，就可以进行coding了。开发大体上和web开发类似，需要注意的是，在调试部分，需要结合真机测试来对比查看效果。因为模拟器、真机测试效果不同是常有的事。其次，微信小程序支持web-view标签，如果你使用外部链接，则需要确保这个网站经过了备案，并且在小程序后台中进行了配置。

配置地址为小程序后台-开发-开发管理-开发设置-业务域名。

如果你想使用npm包，则可以参考以下链接： [开发辅助 / npm 支持](https://developers.weixin.qq.com/miniprogram/dev/devtools/npm.html) 。我参与开发的项目中，使用了vant4，这个包刚好有小程序版本的，只需要将vant4代码复制粘贴到你的工程中，再引入就好了，不需要做额外的工作。所以你想使用一个npm包时，可以先留意是否有小程序版。

###### 2.代码上传

无论你使用微信开发者工具还是uniapp，都需要在微信开发者工具上传代码。上传时，点击微信开发者工具上方的上传按钮，填写版本号和更新日志就可以上传了。

上传完成后，就可以在小程序后台看到体验版小程序，可以扫码进行体验版的测试。需要注意的是，体验版小程序不能在搜索栏中被搜索到，并且，并不是所有的微信账号都有体验版的体验权限，因此，当你想将体验版二维码分享给朋友时，要把他加入到体验版的权限名单。

在体验版测试没问题后，就可以提交审核了，点击提交并填写测试信息后，就会提交审核。审核是微信团队的人工审核，是真人要进行试用，而且还要进行代码审核，确保你的代码没有恶意代码段。每次提交审核，需要等上一次审核完成，同一时间只能有一个版本的小程序在审核。提交时，最好先确保自己的小程序是能正常运行的，不然会被很快驳回。官方明确过驳回的次数过多，会影响之后审核的速度。实际上审核的速度就是很快，短则十来分钟，长则半天。

审核失败时，微信会同时给手机端和电脑端发送审核结果，并且附带失败说明和截图，这时就需要修改代码后，重新上传并提交审核。

审核通过后就可以发布了，发布之前，请先确认自己已经通过了微信认证。发布时有两种发布模式，全量发布和分阶段发布，如果你的小程序使用的人比较多，可以选择分阶段发布。

###### 3.广告的接入

个人开发者几乎唯一的盈利途径就是广告，企业开发者才有资质接入微信支付。广告可以使用微信小程序提供的原生广告，也可以使用其他供应商提供的广告，例如uniapp广告联盟。如果使用uniapp，则可以在官网看到它的广告文档。

小程序达到500个累计独立访客（在23年前是1000个，之后修改为了500个）且没有违规记录后就可以开通流量主接入广告了。广告分为好多种，都可以自行配置，开屏广告是最简单的，一键即可配置，不需要写代码；激励视频广告是收益最高的，可以配置15秒或者30秒，15秒的视频收益会相应降低。给你的工程增加激励视频，需要（相对）比较多的代码支持。一般的逻辑是点“看广告”按钮后，弹出激励视频组件播放视频，播放完成后用户点击关闭，激励视频组件会调用你的下发奖励函数，给完成任务的用户下发奖励；另外像是插屏广告和贴片广告，这些广告没有什么交互性的，只需要贴代码就可以。

广告配置完成后，会给出这个广告的广告位代码，并且带有你专属的广告位id，使用广告组件时，直接复制粘贴给出的广告位代码就可以。最好不要给广告设置过多的样式，因为广告展示不全或者遮挡过多，是不能通过广告审核的。

第一次使用广告组件给小程序添加广告需要审核广告组件，在提交小程序版本审核的同时会提交广告审核。两个审核是分开的，小程序审核通过不代表广告组件审核通过。意思就是，如果你的小程序代码通过审核了，发布正式版后，你的广告第一时间不一定能用，因为此时广告审核还没通过。

广告接入完成后，就可以每天在流量主一栏看到收益了，激励广告的收益一般是每千次20元左右，当然并不固定，这个数字每天都会变化。并且收益计算逻辑是，广告每播放一次，就会有一次的钱，而不是要满一千次才有收益。

###### 4.微信支付

在使用微信支付时，首先要明确你的经营范围，如果类似淘宝需要填写地址发货的，可以使用微信支付；如果是游戏币这类虚拟道具，则必须要使用虚拟支付。而且当你的经营范围涉及文娱、视听这类虚拟内容时，微信会封掉你的微信支付权限，只能使用虚拟支付，防止你用错。

微信支付和支付宝支付类似，都是设置金额后，向微信服务端发送请求就可以；虚拟支付则是需要在小程序后台配置道具或代币，配置道具需要写明数量、金额并配置图片，并且之后想修改价格时，需要同时修改前端调起支付时的价格和小程序后台配置的价格，否则将不能调起支付。

虚拟支付的详细介绍，可以到微信小程序官方文档查看：[微信官方文档 / 虚拟支付](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment.html)

# 开发记录

1.如果要测试，一定要经过模拟器、真机测试、测试版测试和正式版测试。这几个测试得出不同的结果是家常便饭，并且最好准备不同版本的微信，不同版本下的微信，小程序的表现可能也会有差异。

2.如果做短剧小程序，微信会封掉你的video标签，目的是强制你使用微信的媒资管理和短剧播放器，即使后边更改了经营类目，比如修改为教育视频，仍然需要自行申诉来要回video标签的使用权限。

3.微信小程序是可以接入支付宝支付的，这里支付宝官方给出了文档：[微信调用 - 支付宝文档中心](https://opendocs.alipay.com/mini/08dti4)。不过，我目前还没见过哪个小程序真的这么做了。
